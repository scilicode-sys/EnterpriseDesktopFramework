4 · Rythme et conventions

  • Un tour = un commit conventionnel (feat(...), fix(...), test(...), docs(...)), message en français qui dit le pourquoi.
  • Gate avant commit : Release 0 erreur / 0 avertissement, suite 100 % verte.
  • Gate avant rapport : nommer explicitement ce qui n'a pas pu être prouvé et le transformer en recette jouable.
  • Documentation : blueprint + pages de ce dossier mises à jour dans le même commit que la brique.
  • Périmètre : uniquement Framework.* et Framework.sln — la règle d'isolement ne se négocie pas.
